7. 20261012 delete_article_version

## 알려진 빈틈 (솔직히 적습니다)
코드가 쓰는 표 19개 중 이 파일들이 직접 만드는 표는 8개입니다(departments, position_titles, media, article_versions, notifications, audit_logs, ai_draft_sessions, hr_audit_logs). 나머지 11개(profiles, signup_requests, password_reset_requests, projects, articles, article_blocks, article_feedbacks, user_ai_keys, user_ai_prefs, ai_system_settings, ai_call_logs)는 저장소 밖(Supabase 화면)에서 만들어져, **저장소만으로는 같은 DB를 처음부터 다시 만들 수 없습니다.**

## 채우는 방법 (김수현 / 신재완)
1. Supabase 프로젝트 → Settings → Database에서 연결 정보 확인
2. 터미널에서 `supabase db dump --schema public -f supabase/schema_full.sql` 실행 (Supabase CLI 필요)
3. 생성된 `schema_full.sql`을 저장소 `supabase/`에 올림
4. 샘플 데이터가 필요하면 `docs/test-data`의 가상 자료를 사용
※ 비밀번호·키는 파일에 넣지 않습니다.
