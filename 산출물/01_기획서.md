# 01. 기획서 — PRESS-CMS

작성 기준일: 2026-10-13 · 발표: 2026-10-14 · A조(신재완, 김수현)

## 1. 한 줄 소개
기자가 기사를 쓰고, 부장이 검토하고, 출고하기까지의 일을 **한 곳에서** 처리하는 기사 작성·검토·출고 프로그램입니다.

## 2. 왜 만들었나
- 기사 한 편이 글 프로그램, 메신저, 사진 폴더, 메일을 오가며 만들어집니다.
- 수정 요청이 여러 곳에 흩어져 어떤 의견이 반영됐는지 알기 어렵습니다.
- 사진 출처·캡션, 누가 언제 무엇을 바꿨는지 기록이 남지 않는 경우가 많습니다.

## 3. 누가 쓰나 (사용자와 역할)
| 사용자 | 하는 일 |
|---|---|
| 기자 | 기사 작성, 사진 넣기, AI 도움 받기, 검토 요청 |
| 부장·데스크 | 같은 부서 기사 검토, 문장에 의견 남기기, 승인·수정 요청, 출고 |
| 인사 담당자 | 가입 승인, 직원·부서·직책 관리, 비밀번호 분실 처리 |
| 편집국장 | 출고 대기 기사 검토 |
권한 정책: 저장소 `docs/부서별_권한_정책.md`

## 4. 핵심 원칙
1. **기자 중심** — 기사의 주인은 기자입니다. AI는 초안·점검을 돕는 도구이고, 본문에 넣을지는 기자가 정합니다.
2. **사실 우선** — AI에게 “입력된 사실만 사용”하도록 지시하고, 모르는 항목은 [확인 필요]로 남깁니다.
3. **권한은 저장소에서 막기** — 화면을 우회해도 열리지 않도록 데이터 저장소의 규칙(RLS)으로 막습니다.
4. **기록 남기기** — 수정 이력, 업무 이력, 인사 변경 기록을 지우거나 고칠 수 없게 보관합니다.

## 5. 주요 기능 (요구사항 14가지 기준)
기사 초안(질문형) · 자료 정리 · 대화형 수정 지시 · 반복 개선 · 프롬프트 설계 · 단계별 작성 과정 · 사진 설명·인포그래픽 · 웹 자료 가져오기 · 녹음 받아쓰기 · AI 이미지 · 호출 기록 비교 · 출처 표기 · 사실 확인 장치 · 보안
상세는 `02_요구사항_정의서.md`.

## 6. 사용한 기술
React 19 · TypeScript · Vite 8 · Tailwind CSS 4 · TipTap(편집기) · Supabase(로그인·저장소·파일·서버 함수) · Google Gemini / OpenAI / Anthropic Claude · GitHub · Render

## 7. 범위
- 이번 범위: 기사 작성 → 검토 → 승인 → 출고, 미디어 보관함, AI 보조, 인사 관리
- 이후 과제: 영상 내용 분석, 출고 채널 외부 연동, AI 검수 정확도 보강

## 9. 위험과 대응
| 위험 | 대응 |

| AI 서비스 모델 종료 | 월 1회 공식 안내 확인, 설정 화면에서 모델 교체 |
