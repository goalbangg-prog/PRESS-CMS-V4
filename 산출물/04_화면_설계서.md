# 04. 화면 설계서

화면 사진은 발표 자료의 `assets/` 폴더(번호 01~34)에 있습니다. 크기: 로그인 계열(01~04)은 800×915, 나머지 화면은 1920×956(가로세로 약 2:1)입니다. 발표 화면에서 G 키(화면 모음)로도 볼 수 있습니다.

## 1. 화면 목록
| 화면 | 누가 | 내용 | 화면 사진 |
|---|---|---|---|
| 로그인 | 모두 | 이메일·비밀번호, 가입 신청, 비밀번호 분실 | 01_login, 02_signup, 03_password_lost, 04_signup_done |
| 승인 대기 상태 | 신규 가입자 | 대시보드·기사 읽기 전용 | 05~07, 08_password_change |
| 대시보드 | 기자·부장 | 내 할 일, 수정 요청, 출고 대기 | 12_approved_dashboard, 20_manager_project_list, 21_manager_work_dashboard |
| 기사 편집 | 기자 | 워드형 편집기, AI 도구, 피드백, 미디어 패널 | 30~34 (feedback_highlight, ai_review_panel, infographic, ai_draft, media_panel) |
| 검토 | 부장·편집국장 | 출고 대기 목록, 검토 모드 | 13_manager_ready_review_list, 14_manager_review_mode |
| 수정 이력 | 기자·부장 | 이력 보기·복원·삭제 | 29_version_history_delete |
| 미디어 | 모두 | 보관함, 업로드, AI 이미지 | 15_media_upload_dialog, 16_media_library |
| 알림 | 모두 | 종 모양 알림 패널 | 23_notification_panel |
| 설정 | 모두 | AI 키·모델, 일반, 미디어 | 17_settings_ai, 18_settings_general, 19_settings_media |
| 사용법 | 모두 | 역할별 안내서 | 22_guide |
| 인사 포털 | 인사 담당 | 가입 승인, 직원 명부·수정, 부서·직책, 변경 기록 | 09~11, 24~28 |

## 2. 메뉴 구조
```
왼쪽 메뉴
├─ 대시보드 (Dashboard)
├─ 기사 (Article) ── 편집기 ── 미리보기
├─ 미디어 (Media)
├─ 이력 (History) ── 수정 이력 창
├─ 설정 (Settings) ── AI API / 일반 / 미디어 / AI 사용 현황
└─ 사용법 (Guide)
인사 포털 (인사부 계정 전용)
├─ 직원 명부 / 가입 승인 / 비밀번호 분실 신고
├─ 부서 및 조직 관리 / 직책 마스터 관리
└─ 인사·권한 변경 기록
```

## 3. 기사 편집 화면 구성
1. 상단: 제목·부제목·분류·해시태그, 상태 메뉴, 검토 요청 버튼, 알림 종
2. 가운데: 본문(TipTap 편집기). 사진은 끌어서 위치 이동, 마우스를 올리면 자르기·가리기 버튼
3. 오른쪽 패널: 대화·초안(AI 인터뷰) / AI 검수 / 인포그래픽 / 피드백 / 미디어
4. 왼쪽 아래: 기사 원고 분량(글자 수, 공백 포함, 문단 수)

## 4. 화면 흐름
로그인 → (신규: 승인 대기 읽기 전용) → 대시보드 → 새 기사 → 편집(AI 도움) → 검토 요청 → 부장 검토(피드백/승인/수정 요청) → 출고

## 5. 화면 공통 규칙
- 한 화면에서 처리할 수 없는 권한은 버튼 자체를 숨기거나 사유 안내를 보여 줍니다.
- 검토 중인 기사는 본문 수정이 막히고 피드백만 남길 수 있습니다.
- 알림은 새로고침 없이 나타나며, 누르면 해당 기사로 이동합니다.
