## 기능 요구사항 (기사 업무)
| 구분 | 내용 |
|---|---|
| 기사 | 워드형 편집기, 자동 저장(1초 뒤), 글자 수 측정, TXT 가져오기, 워드·텍스트 내보내기 |
| 미디어 | 업로드, 검색, 본문에 끌어놓기, 자르기·확대·가리기, 캡션·크레딧 |
| 검토 | 검토 요청, 수정 요청(사유 필수), 승인, 재검토 요청, 출고 |
| 피드백 | 문장 드래그 → 의견, 형광펜, 답글·해결 처리 |
| 이력 | 수정 이력 보기·복원·삭제, 업무 이력 |
| 알림 | 검토·수정·승인·출고·배정·마감 변경·인사 정보 변경, 새로고침 없이 표시 |
| 계정 | 가입 신청(회사 메일), 승인 전 읽기 전용, 임시 비밀번호, 비활성화 |
| 인사 | 직원 명부, 정보 수정, 부서·직책 관리, 변경 기록(수정·삭제 불가) |

## 비기능 요구사항
- 보안: 비밀 키는 서버에서만 사용, 권한은 저장소 규칙으로 강제
- 사용성: 어려운 용어 없는 사용법 안내 화면
- 추적성: 모든 AI 호출의 기능·회사·모델·응답 시간·글자 수만 기록 (글 내용·사용자 이름 미기록)
