PRESS-CMS 통합 발표자료 (A조 · 발표 신재완 · 팀원 신재완, 김수현)

사용 방법
1. 압축을 폴더째 풉니다.
2. index.html을 Chrome 또는 Edge에서 엽니다. 설치 필요 없음.
3. 스크롤, 방향키, Page Up/Down으로 이동합니다.
4. F: 전체 화면 / O: 전체 목차 / D: 시연 사이트 새 탭으로 열기
5. 사진·도표는 눌러도 커지지 않습니다(발표 진행에 방해되지 않도록).
6. 시연 사이트 버튼: 왼쪽 메뉴, 위쪽 막대, 44번 장. 인터넷 연결이 필요합니다.

구성: 45장
화면 위 빨간 번호 원과 확대 칸은 새 화면 사진(1920×956) 기준으로 위치를 다시 맞췄습니다. 숫자·그래프 애니메이션 포함.
추가한 장: 개발 일정, 팀과 역할, AI는 어디에 쓰였나, 초안 AI 지시문, 사용 모델, AI 서비스 종료 일정과 대응, 기능별 AI 요금,
사용한 프로그램, 한 기능이 지나가는 길, ERD, 화면 구성, 서버 기능 목록, 테스트와 검증 현황, 회고와 개선 계획,
산출물 현황, 사용자 매뉴얼·저장소
산출물 폴더(산출물/): 기획서, 요구사항 정의서, WBS, 화면 설계서, ERD, API 명세서, DB 스크립트 안내, 테스트 결과서, 사용자 매뉴얼, README 수정안, 목록

기능별 AI 요금은 계산한 금액이며 실제 청구와 오차가 있을 수 있습니다.
시험표 36개는 현재 시험 진행 중입니다(AI 초안·자료 정리·보안·안정성·사용 기록은 정상, 나머지는 진행 중).
